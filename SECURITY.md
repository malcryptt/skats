# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| Latest (main branch) | ✅ |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, **do not open a public GitHub issue.** Instead, report it confidentially:

- **Email:** support@skatsconsults.com
- **Subject line:** `[SECURITY] <brief description>`

You will receive an acknowledgement within **48 hours** and a full response within **7 business days**.

Please include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact assessment

We will credit you in the changelog (with your permission) once the fix is deployed.
